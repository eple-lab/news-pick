# 오늘의 뉴스 패키지 만들기

입력 키워드: $ARGUMENTS

## 처리 알고리즘 (이 순서를 지킨다)
1. **키워드·소스 확인**: 키워드가 없으면 기본값(AI, 에이전트, 자동화)을 쓴다.
2. **뉴스 수집**: 웹 검색으로 최근 24시간 기사를 찾는다. 부족하면 최근 3일까지 넓히고, 넓혔다는 사실을 한 줄로 밝힌다.
   - 신뢰할 수 있는 언론사·공식 발표를 우선한다. 뉴스 모음(애그리게이터) 사이트는 원문을 찾는 데만 쓴다.
   - 여러 언론사가 함께 다룬 이슈를 이슈도가 높은 뉴스로 보고 우선한다.
   - 고른 기사는 원문을 직접 열어 날짜와 내용을 확인한다.
3. **중복 제거·필터**: 같은 이슈는 하나로 묶는다. `data/history.md`를 읽고, 최근 14일 안에 다룬 이슈는 제외한다.
4. **요약·인사이트**: 기사 3개를 고른다. 기사별로 직접 쓴 3줄 요약과 핵심 포인트 1개를 만든다.
5. **캡션 결합**: 아래 출력 형식에 맞춘다.
6. **자동 검증**: 아래 체크리스트를 스스로 점검하고, 통과 여부를 마지막에 표시한다. 통과하지 못한 항목은 고친 뒤 다시 점검한다.
7. **사람 검수 요청**: 발행 전에 사용자가 사실관계를 확인해야 한다는 한 줄을 붙인다.
8. **저장·기록**: 결과를 `output/YYYY-MM-DD.md`에 저장한다(같은 날 파일이 있으면 `-2`, `-3`을 붙인다). `data/history.md` 표에 이번 뉴스 3건을 추가한다.

## 출력 형식 (오늘의 뉴스 패키지)
설명(선정 이유, 가정, 검증 결과)과 캡션 본문을 구분한다. 캡션 본문은 코드 블록 하나에 담아 그대로 복사할 수 있게 한다.

1. 훅 (첫 줄, 한 문장)
2. 뉴스 3개: 각각 [제목 / 3줄 요약 / 핵심 포인트 / 출처(언론사명)]
3. 학습자 관점 한 줄
4. 콜투액션 (저장, 공유, 댓글 유도 중 하나)
5. 해시태그 (5~10개)
6. 링크 처리 안내: 인스타 캡션의 링크는 클릭되지 않으므로 캡션에는 "링크는 프로필 또는 댓글 참고"로 안내한다. 링크 목록은 캡션 밖에 별도로 분리해서 제공한다.

## 검증 체크리스트 (모두 통과해야 완성)
- [ ] 뉴스 3개 모두 출처와 링크가 있다
- [ ] 요약은 원문 문장이 아니라 직접 쓴 문장이며, 원문에 없는 내용이 없다
- [ ] 캡션 길이가 1,500자 이내이고(인스타 한도 2,200자), 해시태그가 5~10개다
- [ ] 첫 줄 훅과 마지막 콜투액션이 있다
- [ ] 같은 뉴스를 최근 14일 안에 다룬 적이 없다 (`data/history.md` 기준)
- [ ] 출처는 실제로 원문을 열어 확인한 기사만 캡션에 표기한다.
- [ ] 원문을 못 열었으면 인용한 2차 출처를 표기하고, 설명 영역에 "원문 미확인"이라고 적는다.
- [ ] 원문 미확인 기사가 있으면 검증 체크리스트의 '원문에 없는 내용 없음'은 ✅ 대신 ⚠️로 표시한다.
- [ ] 가능하면 공식 발표(기업 블로그, 보도자료)를 1순위 출처로 삼는다.

마지막 줄: "발행 전에 기사 원문으로 사실관계를 한 번 더 확인해 주세요."
